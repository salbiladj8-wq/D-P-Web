2. Arsitektur Deployment (Vercel Serverless + Supabase)

Secara umum platform Vercel dioptimalkan untuk aplikasi frontend statis dan runtime Node.js. Agar modul backend PHP (Jobsheet 7, Jobsheet 8, dan SISALON) dapat berjalan tanpa server VPS/Apache konvensional, proyek ini mengadopsi pola arsitektur Unified Serverless Gateway.

Komponen Arsitektur:

  • CDN Edge Static (JS 1 - 6): Menangani file statis HTML, CSS, dan JS dengan latensi ultra-rendah langsung dari cache global Vercel.
  • Unified PHP Gateway (api/index.php): Bertindak sebagai router runtime yang menangkap permintaan dinamis PHP, melakukan manipulasi direktori kerja (chdir()), dan mengeksekusi script secara transparan.
  • Cloud Database (Supabase PostgreSQL): Menggantikan PostgreSQL lokal (localhost:5432). Dihubungkan melalui connection pooler AWS Singapura dengan mode keamanan SSL wajib (sslmode=require).
// Potongan konfigurasi koneksi PDO ke Supabase dengan SSL (includes/koneksi.php)
$host = "aws-0-ap-southeast-1.pooler.supabase.com";
$port = "5432";
$db   = "postgres";
$user = "postgres.miqwkcgjrjvqivmrluve";
$pass = "Salbila2506";

$dsn = "pgsql:host=$host;port=$port;dbname=$db;sslmode=require";
$pdo = new PDO($dsn, $user, $pass, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

8. Jobsheet 5: Interaktivitas DOM & Validasi Klien

Menghidupkan antarmuka web menggunakan JavaScript murni (Vanilla JS) tanpa library eksternal.

Fitur & Kodingan Kunci:

  • Mobile Navigation Toggle: Menangkap event click pada tombol hamburger menu untuk menampilkan/menyembunyikan navigasi.
  • Pencarian Real-Time (Live Search): Membaca input ketikan user via event input lalu menyembunyikan baris tabel yang tidak cocok secara dinamis.

// Contoh logika pencarian dinamis pada tabel
const searchInput = document.getElementById('search-input');
if (searchInput) {
    searchInput.addEventListener('input', function() {
        const query = this.value.toLowerCase();
        const rows = document.querySelectorAll('tbody tr');
        rows.forEach(row => {
            const text = row.innerText.toLowerCase();
            row.style.display = text.includes(query) ? '' : 'none';
        });
    });
}

14. Tanya Jawab & Pembahasan Teknis Kodingan (Q&A)

Berikut adalah 10 pembahasan konsep teknis penting seputar implementasi kode pada proyek ini. Klik pada setiap pertanyaan untuk membuka pembahasan lengkap:

1. Mengapa memilih ekstensi PDO daripada mysqli untuk koneksi database? ▼

Jawaban:

  1. Database Agnostik: PDO (PHP Data Objects) mendukung belasan jenis database (PostgreSQL, MySQL, SQLite, Oracle, dll.) hanya dengan mengganti DSN (Data Source Name). Sedangkan mysqli hanya khusus untuk MySQL. Karena di perkuliahan kita menggunakan PostgreSQL (pgsql:host=...), PDO adalah pilihan standar industri.
  2. Keamanan Bawaan: PDO mendukung Prepared Statements dengan parameter binding terpisah, yang secara efektif mencegah serangan SQL Injection.
  3. Object-Oriented API: Error handling PDO menggunakan Exception (PDOException) yang memudahkan penanganan error dengan blok try...catch.
2. Bagaimana cara kerja SQL Injection dan bagaimana kita mencegahnya di kodingan kita? ▼

Jawaban:

SQL Injection terjadi ketika input pengguna digabungkan langsung (string concatenation) ke dalam query SQL, sehingga penyerang dapat menyisipkan perintah SQL berbahaya (misal: ' OR '1'='1).

Di kodingan SISALON dan JS8, pencegahan dilakukan menggunakan Prepared Statements:

// Contoh aman di proses_tambah.php
$stmt = $pdo->prepare("INSERT INTO layanan (nama_layanan, kategori, harga, durasi) VALUES (:nama, :kategori, :harga, :durasi)");
$stmt->execute([
    ':nama'     => $nama,
    ':kategori' => $kategori,
    ':harga'    => $harga,
    ':durasi'   => $durasi
]);

Mesin database akan mem-parse struktur query terlebih dahulu sebelum memasukkan nilainya sebagai data literal murni, bukan instruksi yang dapat dieksekusi.

3. Apa perbedaan mendasar antara Jobsheet 7 (Session) dan Jobsheet 8 (Database)? ▼

Jawaban:

Perbedaan utamanya terletak pada Persistensi (Daya Simpan) dan Skalabilitas:

  • Session (JS 7): Data disimpan di memori/temporary file server dan terikat pada cookie sesi browser. Jika browser ditutup atau server restart, seluruh data hilang. Data juga tidak bisa diakses bersama antar pengguna.
  • Database (JS 8): Data disimpan secara permanen pada disk basis data PostgreSQL. Data bertahan selamanya, mendukung transaksi konkuren multi-user (ACID), pengindeksan, relasi foreign key, dan integritas data.
4. Bagaimana aplikasi PHP bisa di-deploy dan berjalan di Vercel? ▼

Jawaban:

Vercel adalah platform Serverless yang berbasis AWS Lambda. Agar script PHP dapat berjalan, kita menggunakan custom runtime vercel-php@0.7.2 yang dikonfigurasikan di vercel.json.

Setiap ada request ke file PHP, Vercel membungkus PHP CLI/CGI di dalam container serverless function mikro, mengeksekusi script, mengembalikan respons HTTP, lalu kembali ke status idle. Hal ini membuat aplikasi sangat hemat resource karena tidak perlu server yang menyala terus menerus 24 jam.

5. Mengapa HTML semantik (header, nav, main, article) lebih baik daripada hanya memakai div? ▼

Jawaban:

  1. Aksesibilitas (Accessibility / a11y): Perangkat Screen Reader tunanetra dapat membaca struktur halaman secara logis, misalnya langsung melompat ke <main> untuk membaca konten utama.
  2. SEO (Search Engine Optimization): Mesin pencari seperti Google dapat memahami bagian mana yang merupakan navigasi, artikel inti, atau catatan kaki.
  3. Maintainability: Kodingan jauh lebih mudah dibaca dan dirawat oleh sesama programmer dibanding "div soup" (tumpukan tag div tanpa arti).
6. Kapan sebaiknya menggunakan CSS Flexbox, dan kapan menggunakan CSS Grid? ▼

Jawaban:

  • CSS Flexbox (Satu Dimensi): Sangat ideal untuk komponen berbasis baris atau kolom tunggal. Contoh: navigasi bar horizontal, pengelompokan tombol aksi, dan penyusunan kartu ringkasan fleksibel.
  • CSS Grid (Dua Dimensi): Ideal untuk tata letak halaman global yang mengontrol baris dan kolom secara simultan. Contoh: template dashboard dengan sidebar, header, dan konten multi-kolom yang presisi.
7. Mengapa perlu validasi di JavaScript (klien) DAN juga di PHP (server)? ▼

Jawaban:

  • Validasi JavaScript (Sisi Klien): Bertujuan untuk User Experience (UX). Memberikan feedback langsung kepada pengguna jika ada form yang belum terisi tanpa perlu menunggu reload halaman (menghemat bandwidth jaringan).
  • Validasi PHP (Sisi Server): Bertujuan untuk Keamanan (Security). Validasi klien di browser sangat mudah dimatikan atau di-bypass menggunakan inspect element, Postman, atau curl. Oleh karena itu, server WAJIB memvalidasi ulang semua data sebelum disimpan ke database.
8. Mengapa koneksi database ke Supabase memerlukan opsi sslmode=require? ▼

Jawaban:

Ketika aplikasi di-deploy di Vercel (cloud) dan database berada di Supabase (AWS Singapura), lalu lintas data berjalan melewati internet publik. Opsi sslmode=require menginstruksikan driver PDO PostgreSQL untuk mengenkripsi seluruh pertukaran query dan data menggunakan sertifikat TLS/SSL, sehingga kebal dari aksi penyadapan (Man-in-the-Middle Attack).

9. Bagaimana konsep Flash Message bekerja pada aplikasi SISALON? ▼

Jawaban:

Flash Message adalah pesan status yang hanya tampil satu kali setelah operasi berhasil/gagal, kemudian hilang saat halaman di-refresh. Alurnya:

  1. Di proses_tambah.php: Simpan pesan ke session: $_SESSION['flash'] = ['type' => 'success', 'pesan' => 'Data berhasil disimpan!'];
  2. Redirect user ke list.php menggunakan header("Location: list.php"); exit;
  3. Di list.php: Baca pesannya, tampilkan di HTML, lalu langsung hapus dengan unset($_SESSION['flash']);
10. Mengapa digunakan CHECK constraint pada tabel layanan PostgreSQL? ▼

Jawaban:

Pada DDL skema database:

harga INTEGER NOT NULL CHECK (harga >= 0),
durasi INTEGER NOT NULL CHECK (durasi > 0)

Constraint CHECK memastikan integritas data pada layer database paling dalam (Database Level Validation). Hal ini mencegah nilai negatif masuk ke database (misalnya harga minus atau durasi 0 menit), bahkan jika ada bug di level aplikasi PHP.
